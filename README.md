# Horizon Walker — Rift Terminal

A static field database for Horizon Walker, built from data and art compiled on gachawiki.info.

- 64 vanguards, filterable by class, element, and rarity
- 31 story plates (20 world, 11 character CGs)
- 131 skins across 52 vanguards
- 53 patches and 82 banner runs

Open `iterations/02-terminal/` (or the root, which redirects there). No build step — plain HTML, CSS, and JS with all assets local.

Unofficial fan project. Horizon Walker and its art belong to Gentlemanniac.
